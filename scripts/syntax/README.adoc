# Cypher syntax snippets

The syntax snippets are generated from the full Cypher grammar in `full-grammar.bnf`.
The grammar can be downloaded from the internal grammar repo.

## Setup

You must have a recent version (>= 3.12) of Python installed to run the snippet creation/update process.

Create the Python environment from the command line (you only need to do this once):

. Run `python -m venv venv` to create the environment.
. Run `source venv/bin/activate` to activate the environment.
. Run `python -m pip install -r requirements.txt` to install the needed dependencies.

If you close the session or restart the computer, you will need to activate the environment again with `source/venv/bin activate` before continuing.

## Adding a new snippet

With the Python environment active:

. Add the `syntax.adoc` partial with a `:syntax-filename:` attribute (see for example `create.adoc` for reference).
. Add a new `pattern` in the `customization.json` file.
. Run `python update_snippets.py`.

## Updating all snippets

With the Python environment active:

. Copy-paste or download the updated full Cypher grammar file into `full-grammar.bnf`, overwriting the existing file.
. Run `python update_snippets.py`.
. Run `git diff` to check for any changes.
