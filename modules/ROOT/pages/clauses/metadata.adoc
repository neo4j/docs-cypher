= Metadata clauses
:description: Information about Cypher's metadata clauses.

Cypher's metadata clauses provide information about the available procedures, functions, configuration, and active transactions in a database, with `TERMINATE TRANSACTIONS` also allowing for the termination of transactions.

The following clauses are included in this category:

* xref:clauses/listing-functions.adoc[`SHOW FUNCTIONS`]
* xref:clauses/listing-procedures.adoc[`SHOW PROCEDURES`]
* xref:clauses/listing-settings.adoc[`SHOW SETTINGS`]
* xref:clauses/transaction-clauses.adoc#query-listing-transactions[`SHOW TRANSACTIONS`]
* xref:clauses/transaction-clauses.adoc#query-terminate-transactions[`TERMINATE TRANSACTIONS`]
