= Read/Write clauses
:description: Information about Cypher's read/write clauses

Read/write clauses can both both read data from the database, or write to it.

The following clauses are included in this category:

* xref:clauses/merge.adoc[`MERGE`]: ensures that a pattern exists in the graph.
If the pattern exists, `MERGE` matches it; if it does not exist, `MERGE` creates it.
