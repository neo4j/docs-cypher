= Read clauses
:description: Information about Cypher's read clauses.

Cypher's read clauses read data from the database.

The following clauses are included in this category:

* xref:clauses/filter.adoc[`FILTER`]: adds post-match filtering to queries. label:new[Introduced in Neo4j 2025.06]
* xref:clauses/match.adoc[`MATCH`]: specifies the patterns to search for in the database.
* xref:clauses/optional-match.adoc[`OPTIONAL MATCH`]: specifies the patterns to search for in a database, returning `null` for any parts of the pattern that are not found.
