= Composed queries

Cypher contains operators that enable the composition of separate query branches: `UNION` and `WHEN`.
`UNION` allow for the combination of different queries into the same result, while `WHEN` enables the compisiton of conditional queries, where different branches can be made to execute depending on a set criteria.
As such, `UNION` and `WHEN` manage in different ways the execution flow and logic of queries and, therefore, cannot be used as regular clauses.
