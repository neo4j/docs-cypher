= Conditional query constructs

In Cypher, conditional query constructs enable queries to adapt based on conditions.
The `CASE` expression allows conditional logic to determine values or actions based on evaluated conditions, while the `WHEN` condition enables entire sections of a query or subqueries to execute conditionally.
