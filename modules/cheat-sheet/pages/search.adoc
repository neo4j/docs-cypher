[.description]
`SEARCH` can appear in a `MATCH` or `OPTIONAL MATCH` clause.
It filter the results based on approximate nearest neighbor (ANN) vector search.
====

////
[source, cypher, role=test-setup]
----
CREATE VECTOR INDEX `relVectorIndexName` IF NOT EXISTS
FOR ()-[r:REL_TYPE]-() 
ON (r.vectorProperty)
WITH [r.additionalProp]
OPTIONS { 
  indexConfig: { 
    `vector.dimensions`: 3, 
    `vector.similarity_function`: 'cosine' 
  } 
}
----
////

====
[source, cypher, role=noheader]
----
MATCH ()-[r]->()
SEARCH r IN (
  VECTOR INDEX `relVectorIndexName`
  FOR [1, 2, 3]
  WHERE r.additionalProp > 10
  LIMIT 5
) SCORE AS myScore
RETURN r, myScore
----

[.description]
`SEARCH` can also be used for relationships.
`SEARCH` can include an optional `WHERE` subclause for in-index filtering and an optional `SCORE` subcluase to return similarity scores.
====
