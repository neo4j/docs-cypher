= link:{neo4j-docs-base-uri}/cypher-manual/{page-version}/clauses/search/[SEARCH^]

====
[source, cypher]
----
MATCH (n)
  SEARCH n IN (
    (VECTOR | FULLTEXT) INDEX index_name
    FOR query
    LIMIT top_k
  )
RETURN n
----

[.description]
--
Use `SEARCH` within a `MATCH` or `OPTIONAL MATCH` clause to query a Neo4j search index.
There are two variations:

* xref:index.adoc#_search_vector[`SEARCH VECTOR`] uses `VECTOR INDEX` to find similar nodes or relationships.
* xref:index.adoc#_search_fulltext[`SEARCH FULLTEXT`] uses `FULLTEXT INDEX` to find nodes or relationships that match a search string.
--
