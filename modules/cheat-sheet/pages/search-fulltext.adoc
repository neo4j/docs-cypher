= link:{neo4j-docs-base-uri}/cypher-manual/{page-version}/clauses/search/#full-text-search[SEARCH FULLTEXT^]

====
[source, cypher]
----
[OPTIONAL] MATCH pattern
  SEARCH binding_variable IN (
    FULLTEXT INDEX index_name
    FOR query_string [ WITH ANALYZER analyzer_string ]
    [ (SKIP | OFFSET) skip_integer ]
    LIMIT top_k
  ) [SCORE AS score_alias]
----

[.description]
Use the `FULLTEXT INDEX` variation of `SEARCH` to query a full-text index for nodes or relationships that match a search string.
`WITH ANALYZER` and `SKIP` or `OFFSET` are available only for full-text search, and the optional `SCORE` subclause returns each result's relevance score.
====

====
[source, cypher]
----
MATCH (node)
  SEARCH node IN (
    FULLTEXT INDEX content
    FOR 'graph'
    LIMIT 10
  )
RETURN node
----

[.description]
Query a node full-text index for a search string.
The query string can be supplied as a literal, parameter, or property.
The same syntax supports relationship full-text indexes when the binding variable is a relationship from a pattern such as `MATCH ()-[relationship]->()`.
====

====
[source, cypher]
----
MATCH (node)
  SEARCH node IN (
    FULLTEXT INDEX content
    FOR 'graph'
    LIMIT 10
  ) SCORE AS relevanceScore
RETURN node, relevanceScore
----

[.description]
Return the relevance score for each result by binding it with `SCORE AS`.
====

====
[source, cypher]
----
MATCH (node)
  SEARCH node IN (
    FULLTEXT INDEX namesAndTeams
    FOR 'name:"Nils-Erik" OR team:Operations'
    LIMIT 5
  )
RETURN node
----

[.description]
Use Lucene query syntax to search for an exact phrase, combine terms with a boolean operator, and limit terms to specific indexed properties.
See xref:ROOT:clauses/search.adoc#full-text-search-examples[full-text search examples] for more information.
====

====
[source, cypher]
----
MATCH (node)
  SEARCH node IN (
    FULLTEXT INDEX content
    FOR 'graph'
    SKIP 10
    LIMIT 10
  )
RETURN node
----

[.description]
Skip ten ranked results before returning the next ten.
`OFFSET` is a synonym for `SKIP`.
====

====
[source, cypher]
----
MATCH (node)
  SEARCH node IN (
    FULLTEXT INDEX content
    FOR 'running' WITH ANALYZER 'english'
    LIMIT 10
  )
RETURN node
----

[.description]
Select an analyzer for the query with `WITH ANALYZER`.
See xref:ROOT:clauses/search.adoc#analyzers[tokenization and analyzers] for more information.
====
