= link:{neo4j-docs-base-uri}/cypher-manual/{page-version}/patterns/acyclic-paths/[Acyclic paths^]

====
include::{github-raw-page-uri}/docs-cypher/{query-include-branch}/modules/ROOT/pages/patterns/acyclic-paths.adoc[tag=patterns_acyclic]

Prepending a path pattern with the `ACYCLIC` keyword ensure that neither nodes or relationships can be repeated within a path, but nodes can still be repeated across paths to form equijoins.
====
