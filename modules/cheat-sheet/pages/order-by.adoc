====
include::{github-raw-page-uri}/docs-cypher/{query-include-branch}/modules/ROOT/pages/clauses/order-by.adoc[tag=clauses_order_by]

[.description]
--
`ORDER BY` specifies how the output of a clause should be sorted.
It can be used as a sub-clause following link:{neo4j-docs-base-uri}/cypher-manual/{page-version}/clauses/return/[`RETURN`] or link:{neo4j-docs-base-uri}/cypher-manual/{page-version}/clauses/with/[`WITH`].
--
====

====
include::{github-raw-page-uri}/docs-cypher/{query-include-branch}/modules/ROOT/pages/clauses/order-by.adoc[tag=clauses_order_by_multiple]

[.description]
You can order by multiple properties by stating each variable in the `ORDER BY` clause.
====

====
include::{github-raw-page-uri}/docs-cypher/{query-include-branch}/modules/ROOT/pages/clauses/order-by.adoc[tag=clauses_order_by_descending]

[.description]
--
By adding `DESC[ENDING]` after the variable to sort on, the sort will be done in reverse order.

`ORDER BY` can be used in conjunction with `SKIP` and `LIMIT`.
--
====

`ORDER BY` can be used as a standalone clause.
