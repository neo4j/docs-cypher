include::ROOT:clauses/group-by.adoc[tag=clauses_group_by]

[.description]
--
`GROUP BY` is a subclause that gives explicit control over the grouping keys of a link:{neo4j-docs-base-uri}/cypher-manual/{page-version}/clauses/return/[`RETURN`] or link:{neo4j-docs-base-uri}/cypher-manual/{page-version}/clauses/with/[`WITH`] clause.
--
====

====
include::ROOT:clauses/group-by.adoc[tag=clauses_group_by_two_keys]

[.description]
You can group by multiple grouping keys.
====

====
include::ROOT:clauses/group-by.adoc[tag=clauses_group_by_no_keys]

[.description]
You can use group by with no grouping keys by appending `()` to `GROUP BY`.
====


====
include::ROOT:clauses/group-by.adoc[tag=clauses_group_by_all]

[.description]
You can use projected expressions as grouping keys by using `GROUP BY ALL`.
====
