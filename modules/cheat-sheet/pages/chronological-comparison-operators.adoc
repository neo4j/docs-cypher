[.description]
Chronological comparison operators compare temporal values either by instant or by representation.
Cypher contains two chronological comparison operators for ordering: `IS [NOT] BEFORE` and `IS [NOT] AFTER`, and two for equality: `IS [NOT] SAME INSTANT` and `IS [NOT] SAME REPRESENTATION`.
