====
include::ROOT:expressions/predicates/boolean-operators.adoc[tag=expressions_predicates_boolean_operators_and]

[.description]
The `AND` operator is used to combine multiple boolean expressions, returning `true` only if all conditions are true.
====

====
include::ROOT:expressions/predicates/boolean-operators.adoc[tag=expressions_predicates_boolean_operators_or]

[.description]
The `OR` operator is used to combine multiple boolean expressions, returning `true` if at least one of the conditions is true.
====


====
include::ROOT:expressions/predicates/boolean-operators.adoc[tag=expressions_predicates_boolean_operators_xor]

[.description]
The `XOR` operator returns `true` if exactly one of the two boolean expressions is true, but not both.
====

====
include::ROOT:expressions/predicates/boolean-operators.adoc[tag=expressions_predicates_boolean_operators_not]

[.description]
The `NOT` operator negates a boolean expression, returning `true` if the expression is false and `false` if it is true.
====
