= link:{neo4j-docs-base-uri}/cypher-manual/{page-version}/values-and-types/boolean-numeric-string/#string-interpolation[String interpolation^]

====
include::ROOT:values-and-types/boolean-numeric-string.adoc[tag=values_and_types_string_interpolation_property]

[.description]
An interpolated string is prefixed with `s` or `S`, and embeds one or more expressions in curly braces (`{` and `}`).
====


====
include::ROOT:values-and-types/boolean-numeric-string.adoc[tag=values_and_types_string_interpolation_multiple]

[.description]
An interpolated string can contain any number of `\{expression}` placeholders.
====


====
include::ROOT:values-and-types/boolean-numeric-string.adoc[tag=values_and_types_string_interpolation_tostring]

[.description]
Non-`STRING` values embedded in an interpolated string are automatically converted using link:{neo4j-docs-base-uri}/cypher-manual/{page-version}/functions/string/#functions-tostring[`toString()`].
====


====
include::ROOT:values-and-types/boolean-numeric-string.adoc[tag=values_and_types_string_interpolation_escaping]

[.description]
To include a literal curly brace in an interpolated string, escape it with a backslash: `\{` or `\}`.
====


====
include::ROOT:values-and-types/boolean-numeric-string.adoc[tag=values_and_types_string_interpolation_nested]

[.description]
Interpolated strings can be nested, since an embedded expression may itself be an interpolated string.
====
