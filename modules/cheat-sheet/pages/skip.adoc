[.description]
`SKIP` defines from which row to start including the rows in the output.
It can be used in conjunction with link:{neo4j-docs-base-uri}/cypher-manual/{page-version}/clauses/limit/[`LIMIT`] and link:{neo4j-docs-base-uri}/cypher-manual/{page-version}/clauses/order-by/[`ORDER BY`].
====

====

`SKIP` can be used as a standalone clause.
====
