= link:{neo4j-docs-base-uri}/operations-manual/current/procedures/show-procedures[SHOW procedures^]

====
[source, cypher, role=noheader]
----
SHOW PROCEDURES
----

[.description]
Show all procedures in a database and return default columns (`name`, `description`, `mode`, and `worksOnSystem`).
For more information about specifying return columns and filtering, see the general xref:index.adoc#_show[`SHOW`] section.
====


====
[source, cypher, role=noheader]
----
SHOW PROCEDURES EXECUTABLE BY CURRENT USER YIELD *
----

[.description]
Procedures can be filtered on whether a user can execute them.
This filtering is only available through the `EXECUTABLE` clause and not through the `WHERE` clause.
This example filters on the procedures executable by the current user.
====


====
[source, cypher, role=noheader]
----
SHOW PROCEDURES EXECUTABLE BY jake
----

[.description]
Filter on the procedures executable by a specific user.
====
