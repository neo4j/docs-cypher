[.neo4j-ce.neo4j-ee]
====
[source, cypher, role=noheader]
----
SHOW SETTINGS
----

[.description]
List configuration settings (within the instance), returns only the default outputs (`name`, `value`, `isDynamic`, `defaultValue`, and `description`).
====


[.neo4j-ce.neo4j-ee]
====
[source, cypher, role=noheader]
----
SHOW SETTINGS YIELD *
----

[.description]
List configuration settings (within the instance).
====


[.neo4j-ce.neo4j-ee]
====
[source, cypher, role=noheader]
----
SHOW SETTINGS 'server.bolt.advertised_address', 'server.bolt.listen_address' YIELD *
----

[.description]
List the configuration settings (within the instance) named `server.bolt.advertised_address` and `server.bolt.listen_address`.
As long as the setting names evaluate to a string or a list of strings at runtime, they can be any expression.
====
