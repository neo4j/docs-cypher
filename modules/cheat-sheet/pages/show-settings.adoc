[.neo4j-ce.neo4j-ee]
====
[source, cypher, role=noheader]
----
SHOW SETTINGS
----

[.description]
Show configuration settings (within the instance) and return default columns (`name`, `value`, `isDynamic`, `defaultValue`, and `description`).
For more information about specifying return columns and filtering, see the general xref:index.adoc#_show[`SHOW`] section.
====


[.neo4j-ce.neo4j-ee]
====
[source, cypher, role=noheader]
----
SHOW SETTINGS 'server.bolt.advertised_address', 'server.bolt.listen_address' YIELD *
----

[.description]
Show the configuration settings (within the instance) named `server.bolt.advertised_address` and `server.bolt.listen_address`.
As long as the setting names evaluate to a string or a list of strings at runtime, they can be any expression.
====
