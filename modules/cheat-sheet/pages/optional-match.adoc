====
include::{github-raw-page-uri}/docs-cypher/{query-include-branch}/modules/ROOT/pages/clauses/optional-match.adoc[tag=clauses_optional_match]

[.description]
Use `MATCH` to find entities that must be present in the pattern.
Use `OPTIONAL MATCH` to find entities that may not be present in the pattern.
`OPTIONAL MATCH` returns `null` for empty rows.
