[source, cypher, role=noheader]
----
MATCH (n:Label)
WITH n, vector.similarity.euclidean($query, n.vector) AS score
RETURN n, score
----

[.description]
The link:{neo4j-docs-base-uri}/cypher-manual/{page-version}/functions/vector/#functions-similarity-euclidean[`vector.similarity.euclidean()`^] function returns a `FLOAT` representing the similarity between the argument vectors based on their Euclidean distance.
