[.description]
`FILTER` is used to add filters to queries, similar to Cypher's `WHERE`.
Unlike `WHERE`, `FILTER` is not a subclause, which means it can be used independently of the `MATCH`, `OPTIONAL MATCH`, and `WITH` clauses, but not within them.
