include::{github-raw-page-uri}/docs-cypher/{query-include-branch}/modules/ROOT/pages/expressions/string-operators.adoc[tag=expressions_string_concatenation_basic]

[.description]
Cypher contains two operators for the concatenation of `STRING` values: `||` and `\+`
The two operators are functionally equivalent.
However, `||` is GQL conformant, while `+` is not.

[.description]
Concatenating a `STRING` value with `NULL` returns `NULL`.
To skip the first `NULL` value in a list of expressions, use the link:{neo4j-docs-base-uri}/cypher-manual/{page-version}/functions/scalar/#functions-coalesce[`coalesce()`] function.
