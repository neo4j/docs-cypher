====
include::{github-raw-page-uri}/docs-cypher/{query-include-branch}/modules/ROOT/pages/queries/composed-queries/sequential-queries.adoc[tag=sequential_queries_basic_example]

[.description]
`NEXT` allows for linear composition of queries into a sequence of smaller, self-contained segments, passing the return values from one segment to the next.
====

====
include::{github-raw-page-uri}/docs-cypher/{query-include-branch}/modules/ROOT/pages/queries/composed-queries/sequential-queries.adoc[tag=sequential_queries_aggregation]

[.description]
`NEXT` passes the result table as a whole to the subsequent query.
This is particularly useful when aggregating values.
====

====
include::{github-raw-page-uri}/docs-cypher/{query-include-branch}/modules/ROOT/pages/queries/composed-queries/sequential-queries.adoc[tag=sequential_queries_union]

[.description]
If a `UNION` query follows a `NEXT` the full table of intermediate results is passed into all arms of the `UNION` query.
====

====
include::{github-raw-page-uri}/docs-cypher/{query-include-branch}/modules/ROOT/pages/queries/composed-queries/sequential-queries.adoc[tag=sequential_queries_chaining_conditional_queries]

[.description]
`NEXT` can be used to chain conditional `WHEN` constructs.
====
