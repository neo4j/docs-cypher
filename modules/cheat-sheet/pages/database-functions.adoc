The link:{neo4j-docs-base-uri}/cypher-manual/{page-version}/functions/database/#functions-database-nameFromElementId[`db.nameFromElementId()`^] function returns the name of a database to which the element id belongs.
The name of the database can only be returned if the provided element id belongs to a standard database in the DBMS.
