The `SHOW` command can be used to show the metadata of a database or a DBMS
The following variations of the command are available:

* link:{neo4j-docs-base-uri}/operations-manual/current/authentication-authorization/attribute-based-access-control/#_listing_auth_rules[`SHOW AUTH RULES`]
* link:{neo4j-docs-base-uri}/operations-manual/current/database-administration/syntax/#_show_aliases[`SHOW ALIASES`]
* link:{neo4j-docs-base-uri}/cypher-manual/constraints/list-constraints/[`SHOW CONSTRAINTS`]
* link:{neo4j-docs-base-uri}/cypher-manual/schema/graph-types/list-graph-types/[`SHOW CURRENT GRAPH TYPE`]
* link:{neo4j-docs-base-uri}/operations-manual/current/database-administration/standard-databases/listing-databases/[`SHOW DATABASES`]
* link:{neo4j-docs-base-uri}/cypher-manual/functions/show-functions/[`SHOW FUNCTIONS`]
* link:{neo4j-docs-base-uri}/cypher-manual/indexes/search-performance-indexes/list-indexes/[`SHOW INDEXES`]
* link:{neo4j-docs-base-uri}/operations-manual/current/authentication-authorization/manage-privileges/#access-control-list-privileges[`SHOW PRIVILEGES`]
* link:{neo4j-docs-base-uri}/operations-manual/current/procedures/show-procedures/[`SHOW PROCEDURES`]
* link:{neo4j-docs-base-uri}/operations-manual/current/authentication-authorization/manage-roles/#access-control-list-roles[`SHOW ROLES`]
* link:{neo4j-docs-base-uri}/operations-manual/current/clustering/server-syntax/#_list_servers[`SHOW SERVERS`]
* link:{neo4j-docs-base-uri}/operations-manual/current/configuration/show-settings/[`SHOW SETTINGS`]
* link:{neo4j-docs-base-uri}/operations-manual/current/database-internals/show-and-terminate-transactions/#show-transactions[`SHOW TRANSACTIONS`]
* link:{neo4j-docs-base-uri}/operations-manual/current/authentication-authorization/manage-users/#access-control-list-users[`SHOW USERS`]

When used without `YIELD`, the `SHOW` commands only return the default columns.

[.description]
--
The following `SHOW` commands can be combined with general Cypher clauses:

* `SHOW CONSTRAINTS`
* `SHOW CURRENT GRAPH TYPE`
* `SHOW DATABASES`
* `SHOW FUNCTIONS`
* `SHOW INDEXES`
* `SHOW PROCEDURES`
* `SHOW SETTINGS`
* `SHOW TRANSACTIONS`

When combining a `SHOW` command with other clauses, the `YIELD` clause is mandatory and must not be omitted.
`YIELD` must explicitly list the yielded columns.
`YIELD *` is not permitted.
The query must also end with a valid last clause (like a `RETURN` or an updating clause).
