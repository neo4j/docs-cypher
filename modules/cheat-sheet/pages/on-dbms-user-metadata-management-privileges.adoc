----
CREATE ROLE role_name;
----
////

====
[source, cypher, role=noheader]
----
GRANT USER METADATA MANAGEMENT
ON DBMS TO role_name
----

[.description]
Grant `USER METADATA MANAGEMENT` privilege to manage user tags to a role.
This automatically grants `SET USER METADATA` and `SHOW USER METADATA` sub-privileges.
====

====
[source, cypher, role=noheader]
----
GRANT SET USER METADATA
ON DBMS TO role_name
----

[.description]
Grant the privilege to set user tags to a role.
Other options are to allow roles to `ADD` or `REMOVE` tags.
====


====
[source, cypher, role=noheader]
----
GRANT SHOW USER METADATA
ON DBMS TO role_name
----

[.description]
Grant the privilege to view user tags to a role.
====
